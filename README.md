# ReportCenter App

企業報表中心，提供各部門報表管理與查閱。

## 功能

- 年度目標戰情（銷售／接單、月結／即時累計、三區 KPI 與逐月達成率）
- 部門報表瀏覽（分類、搜尋、收藏與外部報表連結）
- 快速存取釘選管理（預設顯示已釘選報表）
- 全站搜尋、報表目錄、權限與使用分析

## 技術

- .NET 10 Razor Pages
- Tailwind CSS 3.4.17（CDN）
- Alpine.js 3.15.12（輕量互動）
- Chart.js 4.5.1（圖表）
- HTMX 2.0.4（局部更新）
- Lucide Icons 1.25.0

## 開發

```bash
cd ReportCenter.Web
dotnet run
```

## 建置

```bash
cd ReportCenter.Web
dotnet build
```

# 04 — 資料庫

系統使用兩個 SQL Server 資料庫，以 Dapper 存取（尚未使用 EF Core：程式註解說明要等 SQL Server 升級後才換）。

| 連線名稱 | 資料庫 | 讀寫 | 內容 |
|----------|--------|------|------|
| `ReportCenter` | ReportCenter | 讀寫 | 報表目錄、分類、部門指派、相依物件、權限、收藏、釘選、使用記錄、首頁戰情 SP |
| `PKSYS` | PKSYS | **唯讀** | 公司既有的部門與人員主檔 |

完整 DDL：`ReportCenter.Web/docs/開發/db-ddl.sql`（可重複執行，皆有 `IF NOT EXISTS`）。

## 1. ReportCenter 資料表

```
ReportCategory 1 ──< ReportCatalog >── ReportDepartment (DeptID → PKSYS.User_Dept，無 FK)
                        │ 1
                        ├──< ReportDependency
                        ├──< UserReportPermission (EmployeeId → PKSYS.User_Profile，無 FK)
                        ├──< UserFavorite
                        ├──< UserPin
                        └──< ReportUsageLog
```

除了 `ReportCatalog.CategoryID` 是 `ON DELETE SET NULL`，其餘所有指向 `ReportCatalog` 的 FK 都是 **`ON DELETE CASCADE`**——刪除一張報表會連帶刪掉它的權限、收藏、釘選與使用記錄。

## 2. Stored Procedure

### `dbo.usp_Rpt_Home_YtdTarget`（ReportCenter DB）

首頁年度目標戰情資料來源。原始碼：`ReportCenter.Web/docs/開發/usp_Rpt_Home_YtdTarget.sql`（2026-07-23 初版，負責人 Clyde）。

**架構**：本 SP 不重算底層數字，而是以 `INSERT … EXEC` 擷取兩支既有 YTD SP 的寬表輸出，再做「RuleCode → 業務區塊」的第二層彙總與百分比計算。

```
usp_Rpt_Home_YtdTarget (首頁組裝層)
  ├─ @Mode = 'S' ─► usp_Rpt_Sales_YtdTargetByGroup  @ReportYear, @CompanyCodeList='TW,SH'
  └─ @Mode = 'O' ─► usp_Rpt_Order_YtdTargetByGroup  @ReportYear, @CompanyCodeList='TW,SH'
```

> 兩支底層 SP 不在本 repo。

**參數**

| 參數 | 值 |
|------|----|
| `@Mode` | `'S'` 銷售 / `'O'` 接單；其他值 `RAISERROR` 並 `RETURN -1` |
| `@CumulativeType` | `'M'` 月結累計 / `'R'` 即時累計；其他值同上 |
| `@ReportYear` | INT NULL；NULL = 系統當年度（首頁一律傳 NULL） |

**業務區塊與 RuleCode 對應**（寫死在 SP 的 `#BlockMap`）

| 區塊 | BlockCode | 幣別欄 | RuleCode |
|------|-----------|-------|----------|
| 外銷 | EXPORT | `_USD` | `SH_EXPORT-A`、`TW_EXPORT-A` |
| 台灣 | TW | `_NTD` | `TW_DOMESTIC-A`、`TW_DOMESTIC-B` |
| 中國 | CN | `_RMB` | `SH_SALES-A`、`SH_SALES-B`、`SH_EC-A`、`SH_EC-B` |

新增或調整業務線時要改這張對應表，否則新的 RuleCode 不會被計入首頁。

**計算規則**

| 項目 | 定義 |
|------|------|
| 截止月 M | 當年度：月結 = 系統當月 − 1、即時 = 系統當月（1 月 + 月結 → M = 0，三區塊金額與走勢全為 0，表示上月尚未結算）；指定過去年度 → 12；未來年度 → 0 |
| 年度目標 T | 區塊內各 RuleCode 在 `ReportMonth = 12` 的 `CumulativeMonthTarget_{幣別}` 加總 |
| 本年累計 A | `ReportMonth = M` 的累計金額（銷售：`CumulativeSaleAmount_*`；接單：`CumulativeOrderAmount_*`，**不含**待確認的 `CumulativeOrderEstimate_*`） |
| 去年同期 L | `ReportMonth = M` 的 `LastYearCumulative*Amount_*` |
| 達成率 | A ÷ T；T = 0 時回 0 |
| YoY | (A − L) ÷ \|L\|；L = 0 時回 0 |
| 走勢 | 每月累計 ÷ 全年目標 T（分母固定），月份由 `master..spt_values` 產生 1 ~ M |

三個區塊由 `#BlockList` 驅動：沒有資料的區塊仍會回傳一列，金額補 0。

**結果集 1：三區塊 KPI**（固定 3 列，依 BlockSort）

`Mode`, `ReportYear`, `EndMonth`, `BlockCode`, `BlockName`, `BlockSort`, `Currency`, `AnnualTarget`, `CumAmount`, `LastYearAmount`, `AchievementRate`（小數，0.1995 = 19.95%）, `YoYRate`（小數，可負）

**結果集 2：逐月累計走勢**（3 區塊 × 1 ~ M 月）

`Mode`, `ReportYear`, `BlockCode`, `BlockName`, `BlockSort`, `Currency`, `ReportMonth`, `CumAmount`, `AnnualTarget`, `TrendRate`

程式端（`YtdBlockKpi` / `YtdTrendPoint`）不讀 `Mode` 欄，其餘欄名需與 C# 屬性一致。

**注意事項**

- 本 SP 內部已使用 `INSERT … EXEC`，因此**不能再被外層 `INSERT … EXEC` 包裝**（SQL Server 不允許巢狀）；程式以 Dapper `QueryMultiple` 讀兩個結果集。
- `#SalesRaw` / `#OrderRaw` 以**欄位位置**對應底層 SP 的輸出。底層 SP 只要增減或調整欄位順序，首頁就會失敗（`Column name or number of supplied values does not match table definition`）。修改那兩支 SP 時必須同步修改本 SP。
- 已依 SQL Server 2008 R2 檢查：使用的 `DECLARE … = 值`、`SELECT INTO`、`master..spt_values`、`RAISERROR` 在 2008 皆可用。

## 4. SQL Server 2008 R2 相容規範 ⚠

**正式環境為 SQL Server 2008 R2（compatibility level 100），開發環境版本較新——本機跑得動不代表正式環境能跑。** 所有 Dapper 查詢、SP、View、Migration 都要主動檢查。

| 禁止（2012+） | 改用 |
|---------------|------|
| `OFFSET … FETCH` | `ROW_NUMBER() OVER (…)` 包子查詢後篩 RowNum（範例：`SqlUsageRepository.GetLogs`） |
| `IIF`, `CHOOSE` | `CASE WHEN` |
| `CONCAT` | `ISNULL(a,'') + ISNULL(b,'')` |
| `TRY_CAST`, `TRY_CONVERT` | 在應用層先驗證 |
| `FORMAT`, `DATEFROMPARTS`, `EOMONTH` | `CONVERT` / `DATEADD` / `DATEDIFF` |
| `LEAD`, `LAG`, `THROW`, `SEQUENCE` | 改寫邏輯 / `RAISERROR` |

可以用的（2008 已支援）：`DATE`、`DATETIME2`、`SYSDATETIME()`、`MERGE`、CTE、`ROW_NUMBER()`。

另外：C# 端的 `"""` 原始字串、`$"""` 插值只是組 SQL 文字，與 SQL 版本無關；但 `WHERE` 動態拼接只能拼**固定片段**，值一律走參數（現有程式皆如此）。

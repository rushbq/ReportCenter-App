## 這個專案在做什麼

ReportCenter（瀏覽器標題「報表中心入口網站」）是**台灣寶工／上海寶工的內部報表入口網站**。

公司實際的報表分散在兩套外部系統：

- **SmartQuery**（`https://pksq.prokits.com.tw/sevi/...`）
- **SSRS**（SQL Server Reporting Services，`http://report.prokits.com.tw/...`）

本站**不產生報表內容**，而是扮演「報表目錄 + 權限閘門 + 使用分析」的角色：

1. 管理者在本站登錄每一張外部報表（名稱、工具類型、連結代碼、所屬部門、分類…）。
2. 管理者以「人」為單位授權誰可以看哪些報表。
3. 員工用 Windows 網域帳號自動登入，依部門瀏覽**自己有權限的**報表，點擊後以新視窗開啟外部報表。
4. 每次點擊都在背景記錄，管理者可以看熱門／冷門報表，作為報表汰除的依據。
5. 首頁另有「年度目標戰情」：外銷／台灣／中國三區的年度目標累計達成率與逐月走勢。

## 使用者與角色

| 角色 | 判定方式 | 能做什麼 |
|------|---------|---------|
| 一般員工 | Windows 驗證通過即是 | 首頁戰情、瀏覽**已授權**報表、收藏、釘選、全站搜尋 |
| 系統管理員 | 員工編號列在設定檔 `AdminUsers` 白名單 | 上述全部 + **看得到所有啟用中報表（不受權限過濾）** + 報表目錄管理、使用分析、權限管理 |

## 功能地圖

| 路由 | 功能 | 對象 |
|------|------|------|
| `/` | 年度目標戰情（三區 KPI、逐月走勢）＋快速存取（釘選報表） | 全員 |
| `/Department?dept={DeptID}` | 部門報表清單（分類 Tab、搜尋、收藏、開啟外部報表） | 全員 |
| 頂欄搜尋 / `Ctrl+K`、`⌘K` | 全站報表搜尋 Dialog | 全員 |
| `/Admin` | 管理總覽（KPI、部門矩陣、孤立報表、冷門報表） | 管理員 |
| `/Admin/Catalog` | 報表目錄 CRUD、啟停用 | 管理員 |
| `/Admin/Usage` | 使用分析（總覽 / 明細查詢） | 管理員 |
| `/Admin/Permission` | 權限管理（批次授權 / 個人權限） | 管理員 |
| `/_diag/windows-auth` | Windows 驗證診斷頁（設定開啟才存在） | 部署除錯用 |

## 技術概要

- ASP.NET Core 10 Razor Pages、Dapper、SQL Server（**正式環境 2008 R2**）
- 前端全走 CDN：Tailwind CSS 3.4.17、Alpine.js 3.15.12、Chart.js 4.5.1、HTMX 2.0.4、Lucide 1.25.0
- Windows 驗證（IIS + Negotiate），開發環境以設定檔模擬 AD 使用者
- Serilog（Console / File / Seq）
- 兩個資料庫：`ReportCenter`（本系統）、`PKSYS`（人事組織，唯讀）
